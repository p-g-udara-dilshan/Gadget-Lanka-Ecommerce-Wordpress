## 🌟 Project Overview

Gadget Lanka was developed to bridge the gap between local tech retailers and consumers. It focuses on a clean, high-performance UI that caters specifically to local user preferences, including localized payment methods and intuitive navigation.

---

## ✨ Core Features

- **💵 Localized Payments**: Full support for **Cash on Delivery (COD)**, catering to the Sri Lankan market.
- **🛍️ Tech-Focused Inventory**: Specialized categories for laptops, smartphones, and accessories.
- **🔍 Smart Search**: Advanced filtering and search functionality to find products quickly.
- **❤️ Customer Engagement**: Wishlist support and personalized user shopping carts.
- **👤 User Accounts**: Customizable user profiles with order tracking and address management.
- **📱 Fully Responsive**: Optimized for a flawless experience on both mobile and desktop.

---

## 🧰 Tech Stack

- **CMS:** WordPress
- **eCommerce Engine:** WooCommerce
- **Backend:** PHP & MySQL
- **Frontend:** Responsive HTML5, CSS3, and JavaScript
- **Plugins:** Wishlist integration, Custom Login, and Profile Editor

## 📂 Deployment

1. Set up a local environment using XAMPP, WAMP, or LocalWP.
2. Clone the repository into your web directory.
3. Create a MySQL database and update the `wp-config.php` file.
4. Access the WordPress admin dashboard to finalize settings.
