## 📖 Overview

Gadget Lanka is a WordPress-based eCommerce portfolio project for a fictional consumer-electronics storefront. It was built to explore how **WooCommerce product management**, browsing, shopping-cart interactions, and a customer-focused visual layout work together.

The website showcases product categories including **smartphones and laptops**, with an emphasis on common online shopping workflows and responsive design.

> **Demo notice:** This project is not presented as an operational retail business. Prices, product entries, sample orders, reviews, and customer-facing statistics may be demonstration content.

## ✨ Features Explored

## ⚙️ Local Setup & Restoration

Unlike a standalone HTML or React project, a WordPress site generally requires a configured **PHP web server**, **database**, **WordPress installation**, and the theme/plugins used by the original website.

To reproduce the original website, the following may be necessary:

1. Install WordPress in a local environment (for example, Local or another PHP/MySQL setup).
2. Install WooCommerce and the theme/plugins used by this specific project.
3. Restore any project-specific theme files, custom CSS, and media files **if available and redistributable**.
4. Import a **sanitized** demo database only if one has been safely prepared for public sharing.
5. Reconfigure the local WordPress site URL, WooCommerce settings, and demo products.
6. Confirm product, cart, wishlist, and checkout behavior in the local environment.

**Important:** Cloning this repository alone may **not** recreate the original website. The exact theme, plugin versions, WordPress database, and custom files must be checked against the files actually included in this repository.

## 🔒 Security & Privacy

- Never publish a real `wp-config.php` with database credentials or WordPress authentication salts.
- Keep database passwords, API tokens, customer records, and payment credentials out of GitHub.
- If any secret was previously committed, **rotate the secret** and remove it from Git history; deleting it only from the latest commit is insufficient.
- Do not distribute premium themes or plugins unless their licenses allow redistribution.
- Share demo data and images only after reviewing privacy and copyright permissions.
