🛒 Gadget Lanka — WordPress eCommerce Website
A responsive WordPress and WooCommerce eCommerce prototype for the Sri Lankan technology market.


Project status: Completed personal development project (May 2025). This website is not currently live and is not an operational online store.

📖 Overview

Gadget Lanka is a personal WordPress eCommerce project exploring how a consumer-electronics storefront could be built for shoppers in Sri Lanka. The website showcases laptops, smartphones, and related products in a structured online catalog, with a focus on straightforward navigation, visual design, and common shopping workflows.

The project provided hands-on practice with WordPress customization, WooCommerce, product presentation, and user-focused website design.

✨ Features
- Tech product catalog: Product listings for laptops, smartphones, and accessories.
- Product discovery: Category-based browsing, search, and sorting options.
- Shopping experience: Shopping cart and wishlist functionality.
- Local checkout option: Cash on Delivery (COD) configuration through WooCommerce.
- Customer accounts: Profile and address-management features.
- Responsive UI: Layouts designed for desktop and mobile viewing.
- WordPress content management: Editable website pages, product information, and storefront content.
Features describe the personal prototype. This repository is not evidence of live order processing or commercial operations.

📂 Repository & Local Setup Notes
This repository serves as a portfolio showcase. A fully restorable WordPress site requires more than WordPress core files. Depending on the original setup, it may also require:
1. The theme and any custom theme modifications.
2. WooCommerce and other plugins used by the project.
3. A sanitized WordPress database export containing the relevant site configuration and demo product content.
4. Media files used in the storefront.
5. Local WordPress/PHP/MySQL environment configuration.
The present repository should not be assumed to contain every asset required to reproduce the exact demo. A complete, shareable development package can be added separately after reviewing third-party licenses and removing private information.

For security, never commit a real wp-config.php, database credentials, authentication salts, payment credentials, or actual customer information.
